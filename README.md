# Máquina Inteligente de Mocktails

Projeto interdisciplinar desenvolvido para o curso da **FATEC**.
O sistema consiste num misturador automático de bebidas controlado por **Spring Boot**, **MySQL** e **ESP32**.

## Tecnologias Utilizadas
- Java 21 / Spring Boot 3
- Spring Data JPA & MySQL
- WebSockets para comunicação com ESP32
- Lombok
